## 描述

App board 的版本详情弹层在窄宽度下信息层级不协调：顶部元信息、更新日志、artifact 列表和操作按钮视觉重量接近，下载与复制按钮抢占内容扫描路径，删除动作也显得孤立。

验收标准：

- 弹层保留 shadcn Dialog 的 header / title / description / footer 组合，并使用项目现有 Badge、Button、Separator 组件。
- 版本状态、更新日志和 artifact 列表层级清晰，移动端和桌面宽度下不挤压、不重叠。
- 操作按钮使用项目 Button 变体和 Phosphor 图标规范，避免手写按钮图标尺寸和自绘分割线。

## 完成描述

已收敛版本详情弹层的信息层级：header 保留版本号、channel/status badge 和状态摘要；内容区改为 toolbar / changelog / artifacts 三段式结构；artifact 行使用更宽的 downloads dialog 尺寸、shadcn Button 变体、Separator 和 `data-icon` 图标规范，移动端与桌面宽度下都避免横向挤压。
