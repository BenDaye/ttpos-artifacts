# BUG-021 构建测试包入口迁移到 Applications

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-07-10
- **related**: PLAN-041

## 描述

Dashboard 的 "Build Test Package" 入口挂在 App detail 页，但现有 `TriggerBuildDialog` 是全局目标选择流：用户需要选择应用端、平台和分支，并不依赖当前 detail 页的 app 上下文。这会暗示当前 app detail 会影响构建目标，和真实交互不一致。

验收标准：

- `/applications` 顶部操作区展示唯一主入口 "Build Test Package"。
- 点击入口后沿用现有 `TriggerBuildDialog`，提交成功后打开现有 `BuildStatusSheet`。
- `/applications/:appName` 不再展示构建入口，也不再持有 build dialog/status state。
- App detail 的 Back 和 Upload version 行为保持不变。
- 不修改 server API、build trigger contract、workflow、权限/限流、轮询语义、routeTree 或 `TriggerBuildDialog` 行为。

## 完成描述

已将构建测试包入口和状态 ownership 从 App detail 迁到 Applications 页；App detail 保留返回和上传版本入口。e2e 覆盖 Applications 触发构建、详情页无构建按钮，以及 320/375px 移动端 header action 不溢出。
