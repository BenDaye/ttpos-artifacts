## 描述

PLAN-004 后续增强。之前用户要补一个新平台/架构的构建产物时，只能进入「Edit version」整体表单，字段繁多容易误改 publish/critical/changelog。本任务在版本卡片头部新增「Add artifact」入口，弹出极简对话框只做「向当前版本追加 artifact」一件事。

### 范围

- 在 `dashboard-next/apps/web/src/features/apps/components/add-artifact-dialog.tsx` 提供 `AddArtifactDialog`，字段仅包含：platform / arch / files / 可选 changelog
- app_name + version + channel 由父级传入的 `AppVersion` 自动带入
- 通过 `useUpdateVersionMutation` 调用现有 `POST /apps/update`（server 已支持在已存在版本上 append artifact，见 `server/mongod/update.go:379-418`）
- 在 `VersionRow` 头部新增 `Add artifact` 按钮触发对话框
- i18n 完整覆盖 en/zh 两语 (`apps.add_artifact.*`)
- e2e：在 `dashboard-next/e2e/app-detail.spec.ts` 增加「点击 Add artifact 打开对话框」用例

### 不在范围内

- intermediate / signature / updater 字段（保留默认，使用旧 `Upload version` 完整表单仍可设置这些）
- 文件大小 / hash 客户端校验（server 已做）

### 验收

1. 进入应用详情页，每个版本卡片头部出现「Add artifact」按钮
2. 点击 → 弹出 dialog，标题为 `Add artifact to {version}`
3. 选 platform + arch + 上传文件后提交 → 成功 toast `Artifact added`
4. 该版本 `Artifacts` 列表追加新条目（依赖 `[app-search]` 失效后重取）
5. typecheck / lint（0 errors）/ e2e 全绿
