# ENH-008: 将 latest 短链改为资源型直达 302

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-09
- **completedAt**: 2026-05-09
- **related**: ENH-007, PLAN-028

## 描述

`/d/<app_alias>/<platform_alias>` 会先 302 到标准 latest URL，再由标准 latest URL 302 到最终 `/download?key=...`。为了让 Cloudflare 更容易缓存固定短链 redirect，并让 URL 看起来像真实下载资源，将短链改为 `/dl/<app_alias>.<package>`，由 server 直接返回最终下载地址的 302。

## 范围

- 将公开短链 route 从 `/d/:app/:platform` 改为 `/dl/:target`。
- app alias 改为 `cashier/assistant/menu/kitchen/shop`，分别映射到真实 app name。
- package target 使用扩展名表达平台与包格式：`apk/exe/dmg`。
- 短链 handler 复用 latest 查询逻辑，成功时直接返回最终 `/download?key=...` 302。
- 移除未投产的 `/download/latest/:owner/:app_identifier/:platform` 公开 route。
- 成功 302 响应增加 Cloudflare edge cache header。
- 更新 API 文档、changelog 和测试。

## 验收标准

1. `/dl/cashier.apk` 查询 `TTPOS + prod + android/arm64/apk` 并直接 302 到最终下载 URL。
2. `/dl/assistant.dmg` 查询 `TTPOS Go + prod + macos/arm64/dmg`。
3. `/dl/shop.exe` 查询 `TTPOS Shop + prod + windows/amd64/exe`。
4. 成功 302 响应包含 `Cloudflare-CDN-Cache-Control: public, max-age=300` 与 `Cache-Control: no-cache`。
5. 未知 alias 或 extension 返回 400。
6. server 不再注册 `/download/latest/*` 公开 latest 下载 route。
7. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。
