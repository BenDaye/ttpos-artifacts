# BUG-007: 修正 Dashboard Next 版本状态与选择器视觉回归

- **status**: completed

## 描述

用户复核 BUG-006 后继续指出以下回归：

1. Version card 顶部 padding 不足。
2. Channel 应放在 version 右侧并 uppercase。
3. Draft / Published / Critical 等状态应通过 version text 颜色区分：Draft 使用默认文字色，Published 使用 primary，Critical 使用 danger；其他组合需明确优先级。
4. 项目内 selector 组件需要统一修复，遵循 DESIGN；option text 需要和 selector icon 对齐，selector padding 需要重新设计。

验收标准：

1. Version card 顶部留白使用 DESIGN spacing token，版本号与 channel 在同一 header 中，channel 位于 version 右侧并 uppercase。
2. Version text 颜色根据状态组合稳定计算，Critical 优先级最高，Published 次之，Draft 为默认。
3. 不再用 Draft / Published / Critical badge 承担版本状态主视觉。
4. Native select 调用收敛到共享选择器组件，padding 与 chevron 使用 DESIGN token，文本与图标垂直对齐。
5. 保持无 hex 字面量、无 Tailwind arbitrary utility，并通过相关 Dashboard 验证。
