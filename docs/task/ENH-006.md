# ENH-006: 收敛公开 latest 下载为单一路由

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-08
- **completedAt**: 2026-05-08
- **related**: ENH-004, ENH-005, PLAN-025

## 描述

公开 latest 下载入口仍同时保留平台级 `/download/latest/<owner>/<app_identifier>/<platform>` 与完整 `/download/latest/<owner>/<app_identifier>/<platform>/<arch>/<package>`。当前发布策略已经确定为单路发布，并且 `arch/package` 已按平台固化，因此公开入口应继续收敛为唯一平台级路由。

## 范围

- 删除 server 中完整公开路由 `/download/latest/:owner/:app_identifier/:platform/:arch/:package`。
- 简化 `PublicLatestDownload`，只按平台查固定 artifact 默认值。
- 移除完整公开路由测试，补充该完整路径不再注册的断言。
- 更新 API 文档、changelog 和相关 PMA 记录。
- 保持 `/apps/latest` query API 与 `/download?key=` 底层文件下载器不变。

## 验收标准

1. server 只注册 `GET /download/latest/:owner/:app_identifier/:platform`。
2. `server/API.md` 只公开平台级 latest 下载 URL。
3. `/download/latest/<owner>/<app_identifier>/<platform>/<arch>/<package>` 不再命中公开 handler。
4. `/apps/latest` 仍可作为显式 `channel/platform/arch/package` 查询 API。
5. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。

## 进行时描述

已移除完整公开 latest 路由，公开 URL 收敛为唯一平台级入口。

## 依赖

- **blocked by**: 用户确认继续按单路发布收敛公开 latest 路由
- **blocks**: latest 下载公开入口投产前语义定版
