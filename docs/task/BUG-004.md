## 描述

BUG-003 将应用详情 version cards 扩展到 1/2/3/4 列，但实际截图显示 version card 承载版本状态、操作按钮和 artifacts 列表后，超宽 4 列会让单卡显得局促。Version 与 platform/channel/architecture 的轻量 taxonomy card 不同，信息密度更高，应保持更宽的卡片宽度。

验收标准：

1. 应用详情 version cards 在宽屏最多 3 列，保持移动端 1 列和中等屏 2 列。
2. 1920px 等超宽屏下不再出现 4 列 version cards。
3. Existing responsive tests 更新为最多 3 列断言，仍验证无 document overflow。
4. 不新增 DESIGN.md 之外的视觉值、hex 字面量或 arbitrary Tailwind value。
