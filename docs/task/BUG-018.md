# BUG-018 修正测试构建应用端卡片与名称

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-07-10 05:47

## 描述

测试构建弹窗的应用端选择卡片在桌面宽度使用三列，中文短名和 package code 同行挤压，导致名称换行且扫描困难；同时应用端中文名称没有对齐 `/dl` short link 和构建能力接口中的产品名。

验收标准：

- 应用端选择卡片在常规桌面弹窗宽度下使用两列布局，避免文字挤压。
- 应用端显示名称优先使用构建能力接口的 `app_name`，并与 short link 产品名保持一致。
- package code 作为辅助信息显示，不抢占主标签视觉层级。

## 完成描述

已将测试构建弹窗的应用端卡片调整为两列布局，显示名称优先使用构建能力接口返回的 `app_name`，并用 short link 风格 alias/package code 作为辅助信息。构建状态抽屉同步使用同一套显示规则。
