## 描述

修复两类可导致服务崩溃的 bug。

### Bug 1: context cancel 误用
`context.WithTimeout` 返回的 cancel 函数被错误命名为 `ctxErr` 并调用，实际上 `ctxErr` 是 error 类型，`defer ctxErr()` 无效，context 永远不会被取消。

涉及 12+ 个 handler 文件，需全局搜索替换。

### Bug 2: 不安全类型断言
`flags["migration"].(bool)`、`adminResult["password"].(string)` 等无 ok 检查的类型断言，数据异常时直接 panic。

验收标准：
1. 所有 `ctx, ctxErr := context.WithTimeout(...)` 改为 `ctx, cancel := ...`
2. 所有 `defer ctxErr()` 改为 `defer cancel()`
3. 所有裸类型断言加 ok 检查
4. `go test ./...` 通过
