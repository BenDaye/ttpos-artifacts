## 描述

用户反馈 BUG-005 版本卡片仍不符合预期，并指出以下具体问题：

1. Version card 样式仍未实现好。
2. Channel chip 应放到 version 左侧。
3. Draft / Published chip 应用颜色区分。
4. Add artifact 中的 select icon 定位偏右，且不需要修改 changelog。
5. Artifacts 不应使用 chip 表现 platform / architecture，只有扩展名的展示也不美观。

验收标准：

1. Version header 使用 channel chip + version + status chip 的明确层级，channel 位于 version 左侧。
2. Published 使用 primary token 实色，Draft 使用 neutral / muted token，二者视觉可区分。
3. Add artifact dialog 移除 changelog 字段，select 使用稳定的 token 化 chevron 定位。
4. Artifact 列表不再使用 chip 展示 platform / architecture；文件名在 package 只有扩展名时回退到 link 中的真实文件名。
5. 保持无 hex 字面量、无 Tailwind arbitrary utility，响应式与 app-detail e2e 继续通过。
