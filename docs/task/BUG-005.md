## 描述

用户反馈 BUG-004 部署后的 version card 仍然不好看。截图显示当前卡片虽然已限制最多 3 列，但视觉层级仍不合理：Draft 顶部胶囊、metadata badge、outline 操作按钮和 artifact 子卡片都在抢主视觉，导致版本号和 artifact 内容不够突出。

验收标准：

1. Version card 遵循根目录 `DESIGN.md` 的 Apple 风格：内容优先、UI chrome 后退、无 decorative shadow。
2. Draft 状态、操作入口和 artifacts 列表改为更克制的层级，不再形成多个抢眼的大按钮/子卡片。
3. 保留 Changelog、Download、Add artifact、Edit、Delete 和 artifact 下载/删除能力。
4. 移动端、桌面端和超宽屏保持无横向溢出，长版本号与长 artifact 名称仍可读。
5. 不新增 DESIGN.md 之外的视觉值、hex 字面量或 arbitrary Tailwind value。
