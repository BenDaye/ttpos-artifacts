# ENH-003: 新增默认 prod 的公开 latest 下载入口

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-08
- **completedAt**: 2026-05-08
- **related**: FEAT-001, BUG-012, ENH-002, PLAN-022

## 描述

显式 latest 路径目前通过 URL 中的 channel 段决定下载哪个 channel 的最新版本，例如 `/latest/<owner>/<app_identifier>/<channel>/<platform>/<arch>/<package>`。面向官网、二维码和普通用户下载时，公开 URL 不应暴露 channel，应该提供默认指向 `prod` 的更短入口，同时保留显式 channel 入口作为底层能力。

## 范围

- 新增不带 channel 的公开 latest 下载入口，默认使用 `prod` channel。
- 保留现有 `/latest/<owner>/<app_identifier>/<channel>/<platform>/<arch>[:package]` 显式 channel 入口。
- CMS workflow 改用公开入口。
- 更新 server route、handler、测试、API 文档和 changelog。

## 验收标准

1. `/download/latest/<owner>/<app_identifier>/<platform>/<arch>/<package>` 默认按 `prod` channel 查询。
2. 现有显式 channel `/latest/.../<channel>/...` 不变。
3. CMS workflow 不再在公开下载查询 URL 中传 channel path segment。
4. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。

## 进行时描述

已完成默认 `prod` 的公开 latest 下载入口，CMS workflow、server route、handler、测试、API 文档和 changelog 均已同步。

## 依赖

- **blocked by**: 用户批准按默认 prod vanity URL 结论开发
- **blocks**: 官网/CMS 使用不暴露 channel 的 latest 下载 URL
