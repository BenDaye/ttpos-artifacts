# ENH-007: 新增极简 latest 下载短链

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-09
- **completedAt**: 2026-05-09
- **related**: ENH-004, ENH-006, PLAN-026

## 描述

当前公开 latest 下载标准 URL 为 `/download/latest/<owner>/<app_identifier>/<platform>`，语义清晰但对官网、二维码和人工传播仍偏长。新增同域短链 `/d/<app_alias>/<platform_alias>`，由 server 直接 302 到标准 latest URL，不依赖额外 DNS 权限。

## 范围

- 新增公开 route `GET /d/:app/:platform`。
- 固定 app alias：`pos -> ttpos`、`go -> ttpos_go`、`menu -> ttpos_menu`、`kitchen -> ttpos_kitchen`、`shop -> ttpos_shop`。
- 固定 platform alias：`a -> android`、`w -> windows`、`m -> macos`。
- 短链只负责映射和 302，不重复 latest 查询逻辑。
- 更新 API 文档、changelog 和测试。

## 验收标准

1. `/d/pos/m` 302 到 `/download/latest/ttpos/ttpos/macos`。
2. 所有 app/platform alias 组合都映射到标准 latest URL。
3. 未知 app 或 platform alias 返回 400。
4. 标准 `/download/latest/:owner/:app_identifier/:platform` 行为不变。
5. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。

## 进行时描述

已新增 `/d/:app/:platform` 短链入口。

## 依赖

- **blocked by**: 用户确认 app alias 使用 `pos/go/menu/kitchen/shop`，platform alias 使用 `a/w/m`
- **blocks**: 官网/二维码使用极简 latest 下载 URL
