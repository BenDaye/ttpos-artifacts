# ENH-005: 移除未投产的 /latest 路由

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-08
- **completedAt**: 2026-05-08
- **related**: FEAT-001, ENH-002, ENH-003, ENH-004, PLAN-024

## 描述

当前实现同时存在 `/latest/*`、`/download/latest/*` 和 `/download?key=`，路由语义不够收敛。由于 `/latest/*` 尚未投产，直接移除该路由，不保留兼容入口；公开 latest 下载统一使用 `/download/latest/*`。

## 范围

- 删除 server 中 `/latest/:owner/:app_identifier/:channel/:platform/:arch[:package]` 路由。
- 删除 `LatestDownload` handler 与接口声明。
- 移除 `/latest/*` route-level 测试，保留 `/apps/latest` query 与 `/download/latest/*` 测试。
- 更新 API 文档与 changelog，明确当前公开入口只有 `/download/latest/*`。
- 保持 `/apps/latest` 查询接口与 `/download?key=` 底层文件下载器不变。

## 验收标准

1. server 不再注册 `/latest/*`。
2. `AppHandler` 不再暴露 `LatestDownload`。
3. `server/API.md` 不再把 `/latest/*` 作为可用 API。
4. `/download/latest/<owner>/<app_identifier>/<platform>` 仍可用。
5. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。

## 进行时描述

已移除未投产的 `/latest/*` 路由；公开 latest 下载入口统一为 `/download/latest/*`，查询 API `/apps/latest` 与底层 `/download?key=` 保持不变。

## 依赖

- **blocked by**: 用户确认直接移除未投产 `/latest/*`
- **blocks**: latest 下载公开路由语义收敛
