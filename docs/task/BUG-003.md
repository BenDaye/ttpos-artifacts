## 描述

BUG-002 上线后继续暴露出 Dashboard Next 的响应式视觉问题：draft version 缺少足够醒目的卡片级标记；应用详情 version cards 仍按单列占满宽度展示，没有按屏幕宽度形成 1-4 列；Statistics 时间范围 button group 选中态仍不明显；共享空状态描述在 `No versions yet`、`No API tokens` 等场景中仍会被挤压成窄列。

验收标准：

1. Draft version 在 version card 上有类似 debug badge 的醒目卡片级标记，不依赖普通 inline badge 才能识别状态。
2. 应用详情 version cards 按屏幕宽度响应式排列，支持 1/2/3/4 列，单个版本不再在超宽屏占满整行。
3. Statistics 时间范围 button group 与 LayoutSwitcher 使用一致且清晰的 selected/pressed 高亮。
4. `EmptyState` 的标题、描述和 action 在所有引用页保持可读，不再被自身或父级 flex/grid 挤压成逐字换行。
5. e2e 覆盖空状态、settings tokens 空状态、Statistics 选中态、version card grid 和 draft badge；本地质量门禁通过。
