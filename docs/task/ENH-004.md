# ENH-004: 公开 latest 下载入口按平台固化 artifact 默认值

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-08
- **completedAt**: 2026-05-08
- **related**: FEAT-001, ENH-002, ENH-003, PLAN-023

## 描述

当前公开 latest 下载入口已经默认 `prod` channel，但仍要求 URL 带 `platform/arch/package`。现阶段产品是单路发布，可以进一步把常用平台的 `arch` 与 `package` 固化，提供更短的公开 URL：`/download/latest/<owner>/<app_identifier>/<platform>`。

## 范围

- 新增平台级公开入口 `/download/latest/:owner/:app_identifier/:platform`。
- 固化默认映射：`android -> arm64/apk`、`windows -> amd64/exe`、`macos -> arm64/dmg`。
- 保留完整公开入口 `/download/latest/:owner/:app_identifier/:platform/:arch/:package` 作为兜底。
- CMS workflow 改用平台级公开入口。
- 更新 server route、handler、测试、API 文档和 changelog。

## 验收标准

1. `/download/latest/ttpos/ttpos_kitchen/android` 默认映射到 `prod/android/arm64/apk`。
2. `/download/latest/ttpos/ttpos_kitchen/windows` 默认映射到 `prod/windows/amd64/exe`。
3. `/download/latest/ttpos/ttpos_kitchen/macos` 默认映射到 `prod/macos/arm64/dmg`。
4. 未知平台在平台级入口返回 400。
5. 完整公开入口仍可显式指定 `platform/arch/package`。
6. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。
