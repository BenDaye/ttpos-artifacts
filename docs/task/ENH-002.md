# ENH-002: latest 路径支持 snake app identifier

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-08
- **completedAt**: 2026-05-08
- **related**: FEAT-001, BUG-012, PLAN-021

## 描述

路径式 latest 下载入口目前要求 path 中传入真实 `app_name`。当应用名包含空格时，外部 URL 必须写成 `%20`，不适合作为官网、二维码或用户可见下载链接。需要在不改数据库 schema 的前提下，支持 `lower_snake` app identifier，例如 `TTPOS Kitchen` 可通过 `ttpos_kitchen` 命中。

## 范围

- `/latest/:owner/:app_name/:channel/:platform/:arch[:package]` 继续兼容真实 app name。
- 当真实 app name 查不到时，在同 owner 的 app 列表中按 normalize 后的 `lower_snake` identifier 匹配。
- 同 owner 下出现多个相同 normalized identifier 时返回明确冲突错误，避免静默错配。
- CMS workflow 改用 snake identifier。
- 补充 server 测试、API 文档和 changelog。

## 验收标准

1. `/latest/ttpos/ttpos_kitchen/prod/android/arm64/apk` 可命中真实 app name `TTPOS Kitchen`。
2. 已有 `/latest/ttpos/TTPOS%20Kitchen/prod/android/arm64/apk` 仍兼容。
3. normalized identifier 冲突时不会随机返回某个 app。
4. CMS workflow 中 FaynoSync app identifier 不再需要 `%20`。
5. 聚焦 Go gate、workflow YAML parse、`git diff --check` 通过。
