# ENH-009: Dashboard Next App board version 快速详情弹层

## 描述

Dashboard Next 的 Applications board 视图当前在点击 version card 时直接进入 app detail 页面。board 本身已经是按应用 column 扫描版本的工作台，点击单个版本后跳页会打断当前 board 滚动位置和横向上下文。需要将 version 点击改为打开 quick detail dialog，并让 dialog 的视觉和信息层级与现有 version card 保持一致。

## 范围

- 在 board 视图中点击 version card 打开 version quick detail dialog，不再直接跳转 app detail。
- Dialog 使用现有 Dialog primitive 与 DESIGN token，不新增非 token 视觉值。
- Dialog 内复用现有 version card 信息层级：version、uppercase channel、状态摘要、artifact 列表和 quick actions。
- 保留 column header 进入 app detail 的行为。
- 增加聚焦 e2e 覆盖 board version dialog 行为。

## 验收标准

1. `/applications` 选择 board 视图后，点击 version card 打开版本详情 dialog，URL 不跳转到 app detail。
2. Dialog 内 version title、channel、Published / Draft / Critical / Intermediate 状态表达与 app detail version card 一致。
3. Dialog 内可以看到 artifact 列表，并保留 download / add artifact / edit / delete 等版本操作入口。
4. Column header 仍可进入 `/applications/:appName`。
5. `dashboard-next` 聚焦 typecheck、lint、e2e 或等价验证通过。

## 进行时描述
