## 描述

`dashboard-next` 在小屏、窄内容区和 board 视图下仍存在文档级横向滚动、导航与内容抢占空间、内容区域不足导致样式崩塌和操作按钮挤压换行的问题。需要在不改变 API 契约、路由、localStorage key、TUF 禁用决策和根 `DESIGN.md` 视觉 token 约束的前提下修复响应式 shell、内容容器和重点页面的收缩边界。

验收标准：

1. 移动端导航不再占用主内容 flex 宽度，内容区域在 320px、375px、768px、1024px 等宽度下不产生文档级横向滚动。
2. 应用 card/list/board 视图、应用详情页过滤器、统计页过滤器和设置页在窄宽度下能稳定换行或局部滚动，不把页面整体撑宽。
3. 过渡效果使用 transform/opacity/width 等明确属性和 motion-safe / motion-reduce 约束，不引入布局抖动。
4. 所有新增视觉值继续来自根 `DESIGN.md` 已映射的 Tailwind v4 `@theme` token；不新增 hex 字面量或 arbitrary value。
5. `dashboard-next` 相关 typecheck、lint、test、build、e2e 或聚焦响应式验证通过。
