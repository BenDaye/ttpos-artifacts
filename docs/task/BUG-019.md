# BUG-019 Fix Upload version form rhythm

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-07-10 07:30

## Description

The Upload new version dialog has uneven form rhythm: select triggers shrink to content width, empty select values render as a tiny icon-only control, and field rows do not align cleanly across horizontal and vertical sections.

Acceptance criteria:

1. Required select fields render with localized placeholder text when empty.
2. Inputs and selects in the main grid use consistent full-width controls.
3. The standalone Architecture field no longer collapses to a tiny trigger.
4. Flag checkboxes, changelog, and artifact sections keep consistent spacing and alignment.
5. Focused frontend verification passes.
