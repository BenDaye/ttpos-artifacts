# BUG-008: Upload version 对话框选择器与文件输入回归

- **status**: completed

## 描述

用户在 Upload new version 对话框里发现以下问题：

1. Channel / Platform / Architecture 三个 selector 弹层飘到了 dialog 之外的右下角，定位完全错乱。
2. 所有 selector dropdown 的第一项都被强行渲染成 `—` 空值选项（带勾），但这些字段都是必填，等于让用户能选择会让校验立刻报错的"空"。
3. Publish / Critical / Intermediate 三个并排的复选框视觉上呈完整圆形，与 radio 单选组难以区分，容易让用户误以为只能三选一。
4. Artifacts 文件输入是浏览器原生 `<input type="file">`，按钮文案 "选择文件 / 未选择任何文件" 跟随系统语言，与 dialog 整体英文不一致。

验收标准：

1. Selector popup 在 dialog 内点开后稳定贴附在 trigger 下方，无飘移、无被 dialog 截断。
2. Required 必填字段的 dropdown 不再混入 `—` 空值选项；如有清空需求需调用方显式声明 clearable。
3. Checkbox 视觉为圆角方形，区别于 radio；视觉变化通过 `--radius-xs` token 实现，不引入 hex / arbitrary value。
4. Artifacts / App logo 等文件输入控件按钮文案跟随 i18n（中英），统一与 dialog 一致。
5. 既有 typecheck / lint / unit / e2e gate 全部通过、无新增 lint warning。

## 进行时描述

完成 selector popup positioning 修复、SelectField placeholder 选项收敛、Checkbox 圆角与 FileInput 控件迁移。

## 笔记

- 2026-05-01 19:35：直接进入实施。

  根因复盘：
  - Selector 飘移：`DialogContent` 用 `-translate-x-1/2 -translate-y-1/2` 居中，CSS transform 父级会把内部 `position: fixed` 元素相对 transform 框定位（containing block）。而 `SelectContent` 缺少 `<BaseSelect.Portal>`（Base UI v1.0.0-alpha.5 起 Select 必须显式包 Portal），导致 Positioner 留在 dialog DOM 内、被 transform 劫持。
  - `—` 空选项：`SelectField` 在 popup 起始位置硬塞了 `<SelectItem value="">{placeholder}</SelectItem>`，对所有调用都生效，没有给必填字段例外的余地。
  - Checkbox 像 radio：`--radius-sm` 在本项目设计 token 中是 8px，与 16px (`size-4`) Checkbox 的半径正好相等 → 视觉退化为圆。
  - 中文按钮：浏览器对 `<input type="file">` 的内置控件 i18n 不可改，必须包一层自定义 button。

  修复：
  - `select.tsx`：用 `<BaseSelect.Portal>` 包 Positioner，popup 通过 portal 脱离 dialog 的 transform 包围，并显式抬到 `z-[60]` 高于 dialog backdrop。
  - `select.tsx`：`SelectField` 增加 `clearable` prop（默认 false），仅在调用方显式声明时才渲染空值选项。当前所有调用点都是 required 字段，故全部走默认 false。
  - `checkbox.tsx`：圆角从 `rounded-sm` (8px) 改为 `rounded-xs` (5px)，让 16px checkbox 视觉上保持方形，与 radio 区分。
  - `file-input.tsx` 新增共享组件：用隐藏 `sr-only` 的 `<input type="file">` + 可见 `Button` 触发 + 文件名/计数 summary，buttonLabel/emptyLabel 由调用方传入 i18n 已 resolved 的字符串。
  - `common.json` 新增 `file_input.choose_one / choose_many / empty` 词条（中英）。
  - upload-version-dialog / add-artifact-dialog / app-form-dialog 的 native file input 全部切换到 FileInput。

  验证：`bun run typecheck`（pass）、`bun run test` 12/12（pass）、`bun run build`（pass）、`bun run lint`（0 errors，46 既存 warnings、无新增）、`bun run test:e2e` 80/80（focused upload/add-artifact 5/5 + 全套 80/80）。
