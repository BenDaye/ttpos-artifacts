## 描述

BUG-001 修复了 document 级横向滚动和移动端导航抢占空间，但实测仍有几个细节不符合预期：应用详情空状态 `No versions yet` 文案在窄屏被压缩；应用列表搜索框缺少聚焦展开反馈；布局切换器选中态不够明显；应用详情 version row 仍偏向单行头部布局，没有充分考虑长版本号、多 badge、多 artifact 和多操作按钮的情况。

验收标准：

1. EmptyState 在窄屏下有可读的标题、描述和按钮布局，不再被过大 padding 或 max-width 压缩。
2. 应用列表及同类搜索框具备 token 化的 focus-within 展开/强调效果，且不引入 document 横向滚动。
3. LayoutSwitcher 当前选中布局有清晰高亮，使用 `DESIGN.md` 已映射 token，不新增硬编码颜色。
4. 应用详情 version row 支持多行信息架构：长版本号、badge、操作按钮和 artifact 信息能分区换行，不假设单行展示。
5. 相关 responsive e2e 或 focused e2e 覆盖上述行为，质量门禁通过。
